# Drawing for the CRT

Shotgun Kid's art is drawn for its CRT filter, the way 16-bit era artists drew for the televisions of their day. The filter (`assets/shaders/crt.gdshader`, the Heavy preset; `crt_light.gdshader` is a gentler Light preset) works on the game's 640x360 pixel grid:

- **The beam blurs each line horizontally** across neighbouring game pixels (`beam_blur`, about half a game pixel). Two colours alternating pixel by pixel melt into the colour between them.
- **Every row of game pixels is one scanline.** The beam is taller where a row is bright, so highlights swell and glow while darks stay crisp.
- **Bright pixels bleed a little light** into their neighbours (`glow`), and a faint aperture-grille mask and colour misconvergence sit on top.

## Rules the art follows

- **Dither instead of banding.** Gradients (skies, bevels) use a 4x4 ordered Bayer pattern between fine colour steps; on screen they read as smooth ramps. See `gradient()` in `tools/art_biome_backgrounds.lua` and the dusk sky in `tools/art_props.lua`.
- **Checkerboards are half tones.** A 50% checker of two neighbouring ramp colours reads as one colour between them. Terrain uses this for the half step of depth shading two tiles into a wall (`tools/art_terrain.lua`), and buttons use it for their soft top highlight.
- **Spend single bright pixels on purpose.** One near-white pixel blooms into a glint: eye catchlights, the shell's brass glint, ice and spike tips, the Comet Blaster's coil. Don't scatter lone bright pixels as noise.
- **Keep a dark outline on gameplay sprites.** The ink outline (`1c1a30` / `202139`) survives the horizontal blur and keeps the kid, guns and pickups readable. Scenery props instead get an outline in a darker shade of their own colour, so they stay behind the action.
- **Fog with dither, rim with light.** Backdrop layers fade toward their haze colour in dithered eighths, more toward the bottom, and every silhouette gets a lit top edge (`tools/art_depth.lua`).
- **Never dither a stretched area.** Nine-slice centres stretch, so dither only inside the margins (see the button bevels in `tools/art_menu_ui.lua`).
- **Tile patterns repeat every 16px and never depend on the tile variant**, so neighbouring tiles always meet seamlessly; variants differ only in decorations kept 2px from the edges.

## Art scripts

All art is generated by Aseprite Lua scripts (`Aseprite -b --script-param root=<project> --script <script>`):

| Script | Draws |
| --- | --- |
| `tools/art_terrain.lua` | All five terrain atlases (128x128; layout in the script header) |
| `tools/art_wardrobe.lua` | The kid's 16 poses, outfits, hats, neck wraps, scarves and the eight shotguns |
| `tools/art_props.lua` | Shell pickup, spikes, and the Lantern Ridge dusk sky and mountains |
| `tools/art_decor.lua` | Eight scenery props per world (four worlds), with soft self-coloured outlines |
| `tools/art_depth.lua` | Shared dithered fog ramp and silhouette rim light for backdrop layers |
| `tools/art_biome_backgrounds.lua` | The four biome backdrops (dithered skies) |
| `tools/art_menu_ui.lua` | Buttons, panels, HUD frames and ammo icons |

`tools/art_lantern_ridge.lua` and `tools/art_level_themes.lua` are older full rebuilds. They would overwrite the newer terrain, shell, spikes and sky, so don't run them.

`tests/capture_art.gd` screenshots the menu, the Shotguns wardrobe tab and several levels for review (run it windowed, with `-- --out=<folder>`).
